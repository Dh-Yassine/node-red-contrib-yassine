# node-red-contrib-yassine

## Overview
This node replaces any incoming payload with the string "Yassine".
Even if the input is not a string, "Yassine" is returned.
It was built from the lower-case sample node as part of an IoT lab exercise.

## How to use
Place it between an inject node and a debug node. Whatever the inject sends, the debug tab shows "Yassine".
